# 工艺包编制要求（SHSG-052-2003，初步设计 / 详细设计级）

严格按 SHSG-052-2003，工艺包须包含以下 18 章。每套工艺包（路线 A、路线 B）均须给出具体尺寸/
装填量/操作条件/压降/材质/控制联锁，达初步设计 / 详细设计深度。

1. **总论**
2. **设计基础**
3. **工艺说明**
4. **物料和能量平衡（计算书）**
5. **PFD（文字+框图）**
6. **P&ID（关键控制回路）**
7. **设备选型与数据表（含反应器结构图）**
8. **仪表与自动控制**
9. **安全与环保**（含 HAZOP/LOPA/SIL 摘要、事故工况）
10. **分析化验计划**
11. **操作原则与开停车**
12. **公用工程**
13. **三废处理**（含 CCUS/碳足迹）
14. **技术经济分析**（全 CAPEX/OPEX/NPV/IRR/平准化成本）
15. **催化剂规格书与装填**
16. **计算模型说明与 HTML 手册**
17. **RAM/运维与培训仿真**
18. **原料灵活性与最严苛工况方案**

## 深度要求

- 设备数据表：含入口/出口 T/P、压降、GHSV、装填量、床高/径、材质、内构件、结构设计
  （床层支撑、气体分布器、卸剂口、检修人孔、防焦油凝结、热膨胀补偿）。
- 控制联锁：反应器温度高高/低低、床层压差高高、可燃气体泄漏、紧急泄压、进料切断、
  惰性吹扫、蒸汽灭火等须在 P&ID 与第 8、9 章一致。
- 计算模型：每模型至少 1 个文献/工业数据验证对比；说明适用范围/局限；附敏感性图。
- 投资/成本：明确标注"概算/估算，待详细报价确认"；给出量级依据（类比项目/供应商询价区间）。
- 缺失数据：先按典型文献假设并标"假设，待用户确认"，留修正接口，不得作最终设计依据。
