# 统一输入边界（所有 Subagent 共用）

> 主 Agent 必须将本文件作为 SA-1~SA-10 的统一输入基线，确保并行计算输入一致。
> 缺失数据标"假设，待用户确认"，不得作最终设计依据。

## 1. 原料与规模

- **原料**：生物质颗粒料（松木、树皮、森林残余物、拆除木材、小麦秸秆等），模型中须作**原料灵活性**输入，
  评估碱金属/Cl 波动对下游影响。
- **气化炉类型**：流化床气化炉（CFB/BFB）。
- **粗合成气干气流量基准**：**22000 Nm³/h**（两路线基准；路线 B 可作可调参数）。

## 2. 路线 A：纯氧蒸汽气化炉出口粗合成气

- **温度**：850–900 ℃
- **压力**：**1.0 MPa(g)**
- **干气组成（vol%）**：CO₂ 23.5 / CO 26.0 / H₂ 30.4 / N₂ 11.8（差值）/ CH₄ 7.27 /
  C₂H₂ 0 / C₂H₄ 0.83 / C₂H₆ 0.27 / C₃+ 0
- **湿燃气含水率**：24.5%（vol）
- **硫化物**：H₂S 0.003% / COS 0.0004%（vol）
- **NH₃**：0.03%（vol）
- **焦油（每标方干气）**：苯 11.3 g/Nm³；可凝焦油（不含苯）5.8 g/Nm³；重质烃 1.9 g/Nm³；
  **总焦油（含苯）= 19.0 g/Nm³**
- **粉尘**：20–30 g/Nm³（干气）

## 3. 路线 B：空气气化炉出口粗合成气

- **温度**：850–900 ℃
- **压力**：**10–20 kPa(g)**
- **干气组成（vol%）**：CO 16.3 / CO₂ 14.4 / H₂ 13.1 / N₂ 50.7（差值）/ CH₄ 3.8 /
  C₂–C₅ 1.5 / NH₃ 0.17
- **湿燃气含水率**：12.5%（vol）
- **HCN**：160 ppmv（干气）
- **焦油（总焦油+苯，干气基准）**：**17.5 g/Nm³（干气）**，催化段须达 **≥99.7% 转化率**
  （出口 ≤50 mg/Nm³）。
- **粉尘**：未提供 → 假设 10–30 g/Nm³，标"待确认"；作关键敏感性参数（10/20/30 三档）扫描。
- **HCl/Cl**：气相 HCl 估 0.009 vol% 量级，标"估算，待确认"；碱金属（Na/K）按文献典型值假设。

## 4. 下游产品规格要求

### 4.1 绿色甲醇合成气（路线 A）
总焦油≤5 mg/Nm³（干基）；硫≤0.1 ppmv；氯≤0.1 ppmv；H₂/CO 2.0–2.2；CO₂≤3–5 vol%；
惰性气(N₂+Ar)≤3 vol%。

### 4.2 SAF 合成气（路线 A，费托）
总焦油≤5 mg/Nm³；硫≤0.01 ppmv；氯≤0.01 ppmv；H₂/CO≈2.0；CO₂≤5 vol%；惰性≤5 vol%。

### 4.3 内燃机/燃气轮机燃料气（路线 B）
总焦油≤5 mg/Nm³；颗粒物≤10 mg/Nm³；硫≤20 ppmv；氯≤10 ppmv；NH₃≤10 ppmv；
热值≥5.0 MJ/Nm³；压力 0.1–0.5 MPa，温度 40–60℃。

## 5. 焦油脱除核心目标

- **催化段出口设计值**：总焦油（含苯）≤ **50 mg/Nm³**（干基）。
- **全流程最终出口（深度脱焦油后）**：≤ **5 mg/Nm³**，苯单独报告。
- **绝对上限**：催化段出口不得长期>50 mg/Nm³；全流程出口不得长期>10 mg/Nm³。
- **检测方法**：CEN/TS 15439 或用户指定。
- **基准统一**：所有焦油浓度统一为**干气基准（Nm³ dry）**，避免湿基/干基混淆导致单位错位。

## 6. 原料灵活性边界

- 评估 5+ 种生物质碱金属（Na+K）、Cl、S、N、灰熔点差异对下游影响。
- 给出"最严苛原料工况"（高碱金属+高 Cl，如秸秆）下的保护床/脱氯/防腐蚀强化方案。
- 原料属性作可调矩阵输入。

## 7. 界区与接口条件

- **上游交接点**：气化炉出口管道法兰（条件见上）。
- **下游交接点**：路线 A 合成气外送界区（至甲醇/SAF）；路线 B 燃料气外送界区（至内燃机/燃气轮机）。
- 界区交接须给出：压力、温度、流量、组成、尘/硫/氯/氨/焦油浓度、法兰标准与责任方划分。
- 公用工程接入点：电、仪表风、工厂风、循环水、蒸汽（高/中/低压）、脱盐水、氮气/惰性气、排污点，
  界定供应边界与规格。
- 以"界区条件表"单列，作为初设/详设接口冻结依据。
