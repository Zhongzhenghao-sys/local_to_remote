# 数据来源与引用规范

## 统一文献库管理办法

- 主 Agent 维护**单一编号库**（REF-001, REF-002, …）。
- 各 Subagent 引用须归入此库，**禁止各自编造编号**，避免重复/冲突。
- 引用编号在正文以 `[REF-XXX]` 形式标注。

## 引用规范

1. 关键数据/配方/供应商/案例须编号引用。
2. 参考文献格式遵循 **GB/T 7714**。
3. 专利/论文/报告/标准/新闻均标注。
4. **提供可访问网址**（DOI / 官网 / 专利号 / 报告 PDF）。
5. 内部数据或待确认信息标 **"待确认"**。
6. **不虚构数据**；缺失可估算并标 **"估算值"**；推测标 **"推测，未经证实"**；典型文献假设标
   **"假设，待用户确认"**。
7. 物性/动力学/失活参数须给出来源。
8. 所有"概算/估算"成本须标注量级依据（类比项目/供应商询价区间），不得作最终设计依据。

## 标注标签速查

| 标签 | 含义 | 使用场景 |
|---|---|---|
| `待确认` | 用户未提供、需补充 | 缺失的输入参数（如路线 B 粉尘） |
| `估算值` | 基于典型值推算 | 缺失但需先填数推进计算 |
| `假设，待用户确认` | 典型文献假设 | 留修正接口，不作为最终依据 |
| `推测，未经证实` | 无公开方案时工程推测 | 商业化问题/方案推测 |
| `概算/估算，待详细报价确认` | 投资/成本 | 所有 CAPEX/OPEX |

## 引用条目示例（供模板）

```
[REF-001] Author A, Author B. Title of paper[J]. Journal Name, Year, Vol(Issue): Pages. DOI: xxxx
[REF-002] Company C. Product Datasheet: Catalyst X[R]. Year. URL: https://...
[REF-003] Standard S. SHSG-052-2003 工艺包编制规定[S]. Year.
```
