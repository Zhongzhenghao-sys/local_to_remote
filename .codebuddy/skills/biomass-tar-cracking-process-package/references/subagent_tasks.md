# Subagent 任务定义（SA-1 ~ SA-10）

> 各 Subagent 独立产出其负责章节的草稿、计算与引用，主 Agent 汇总并消除冲突。

## SA-1 全球情报/技术调研（章节：四·1、七·3）

1. **商业化焦油催化裂解/重整技术**：列表对比 VTT（芬兰）、Güssing FICFB、TNO/ECN（OLGA）、
   Fraunhofer IGU/IKTS、Haldor Topsoe、Johnson Matthey(KATALCO)、Clariant/Süd-Chemie、BASF、
   UOP/Honeywell、Axens；国内：中科院大连化物所、山西煤化所、华东理工、浙江大学、太原理工等。
   每项列：催化剂型号/牌号/活性组分/载体/助剂；应用项目/地点/规模(t/d 或 MWth)；气化炉类型；
   操作 T/P/空速；焦油进/出口；连续运行时间、失活、再生方式；运行现状（在运/停运/示范/中试）；
   **商业化运行常见问题及解决措施**（积碳、硫中毒、压降升、磨损、换热器堵、腐蚀、焦油聚合）。
   无公开方案时标"推测，未经证实"。
2. **非催化部分氧化 POX**：原理、工业案例（Shell、GE/Texaco、ThyssenKrupp Uhde）；对比催化：
   投资/操作成本/氧耗/碳效率/焦油转化率/耐硫氯/合成气 H₂/CO/炭黑/材料/成熟度；商业化问题及解决方案。
3. **其他非物理脱除方法（仅大规模商业化）**：高温热裂解、油洗/水洗（OLGA，注环保问题）、等离子体、
   微波、化学吸收/转化。筛选标准：仅列已商业化投产（>中试），否则标"无大规模商业化，不推荐"。
4. **催化剂供应商对比**：供应商/牌号/特点/业绩/供货/知识产权风险/价格。

## SA-2 催化剂研发（章节：四·2、五·5、七·1）

1. 商业化催化剂调研：Ni 基、贵金属(Rh/Pt/Pd)、碱金属、钙钛矿、橄榄石、白云石、SiC 载体等；
   供应商/牌号/组成/物性（比表面、孔容、强度、堆密度）；操作窗口；
   **毒物耐受性**：H₂S/COS/HCl/碱金属/重质焦油/颗粒物耐受浓度(ppmv 或 mg/Nm³)、失活速率、再生。
2. 推荐体系：路线 A/B 主催化剂+辅助；能否通用？给依据；若"有条件通用"给具体方案（操作参数/保护床）。
3. 制备路线：浸渍/共沉淀/挤出/焙烧/还原钝化/成型；主要设备清单。
4. 失活与再生：硫/氯/积碳/烧结/磨损/碱金属沉积机理；空气/蒸汽再生、在线烧炭、更换周期；
   失活动力学或工业数据。
5. 催化剂配方数据库：组成/物性/窗口；装填体积/质量/成本；保护床/主床结构；规格书。

## SA-3 反应工程/动力学（章节：四·3、五·4）

1. 反应网络：焦油→CO+H₂+CH₄+C+PAH；甲烷蒸汽/干/部分氧化重整；氨分解/氧化；水煤气变换。
2. 操作参数敏感性：T/P/空速/汽碳比/氧碳比 对 焦油/甲烷/氨转化率、积碳速率 的定量曲线或表。
3. 失活模型：活性系数随 时间/累积焦油/硫暴露 变化的方程与参数，可嵌入 Python。
4. 文献/专利速率方程；一维拟均相固定床；沿床层 T/浓度分布；结合失活算寿命/再生周期。

## SA-4 反应器/设备设计（章节：四·4、五·3）

1. **类型选择**：固定床(保护床+主床)/流化床/移动床/径向床；选型依据：焦油量、颗粒物、气量、
   操作弹性、压降、再生方式。
2. **设计参数**：入口/出口 T、P、压降、GHSV、装填量、床高/径、材质（耐高温/耐硫腐/耐磨）、内构件
   （分布器、支撑格栅、防结焦）。**必须含结构设计**：床层支撑、气体分布器、卸剂口、检修人孔、
   防焦油凝结、热膨胀补偿。出设备数据表。
3. **预处理流程**：高温除尘（旋风/陶瓷滤芯/金属滤芯/颗粒床）；降温（余热锅炉/激冷/换热网络）；
   预脱硫脱氯（ZnO/NaHCO₃/活性炭）；是否在反应器内连续除灰/在线再生；须有商业化/中试案例支撑。
4. 按空速/线速/压降（Ergun）算直径/床高/装填量；壁厚/材质；温升（绝热温升）。

## SA-5 工艺集成/净化（章节：四·5）

1. **路线 A → 绿色甲醇/SAF**：催化裂解后衔接：颗粒物脱除；脱硫（低温甲醇洗/胺洗/ZnO 精脱硫）；
   脱氯（活性炭/碱洗/氧化铝）；CO 变换/部分变换调 H₂/CO；脱碳（低温甲醇洗/MDEA/PSA）；
   深冷/PSA 提氢；脱水；**下游深度脱焦油单元**（吸附床活性炭/分子筛/特殊吸附剂、二次催化、溶剂吸收），
   确保总焦油≤5 mg/Nm³。溶剂吸收须含废液处理工艺；注明商业化案例。
2. **路线 B → 热电联产燃料气**：除尘、降温、脱硫、脱氯、除氨；增压/调压；**下游深度脱焦油单元**
   （吸附/精滤/催化氧化）确保燃料气规格。
3. **换热网络与蒸汽/水平衡**：全流程换热网络（Pinch 分析思路）、蒸汽系统（产汽/用汽/背压/抽汽）、
   水平衡（补充水/循环水/废水），与 SA-7 协同。

## SA-6 安全/HAZOP/LOPA（章节：四·6、六·9）

1. **HAZOP**：以 P&ID（SA-5）为对象，按引导词（无/多/少/反向/伴随/部分/异常）逐节点
   （气化出口→除尘→预热→催化反应器→深度脱焦油→下游）识别偏差、原因、后果、现有措施、建议措施。
2. **LOPA**：对重大后果场景做半定量保护层分析，确定所需 SIL 等级。
3. **SIL 定级与 SIS**：安全仪表功能清单、SIL 等级（1/2/3）、表决架构（1oo2/2oo3）、
   SIS 与 BPCS 独立原则（IEC 61511）。
4. **关键安全联锁**：反应器温度高高/低低、床层压差高高、可燃气体泄漏、紧急泄压、进料切断、
   惰性吹扫、蒸汽灭火。
5. **事故工况设计**：飞温（热失控）、气体泄漏（H₂/CO）、焦油着火、催化剂粉尘爆炸、高压串低压、
   断电/断仪表风/断蒸汽的失效安全响应。
6. 消防（泡沫/水喷雾/气体灭火）、气体检测（H₂/CO/CH₄/NH₃）、爆炸通风、抗爆设计原则。

## SA-7 三废/低碳/水平衡（章节：四·7、六·13）

1. **废水**：含酚焦油废水、含氨废水、含硫废水；处理工艺（萃取/生化/湿式氧化/汽提）、达标或回用。
2. **废气**：再生尾气（含焦油/NH₃/硫化物）、火炬系统、VOCs 治理。
3. **固废/废剂**：废催化剂（含 Ni/贵金属）、废吸附剂、飞灰/底渣；危废鉴别、处置/再生/金属回收。
4. **CCUS**：路线 A 下游脱碳 CO₂ 捕集、纯度、压力、利用（制绿色甲醇原料/封存/EOR）；
   碳效率与碳损失核算。
5. **碳足迹/LCA**：基于 ISO 14040/14067，以 1 Nm³ 产品气或 1 t 甲醇/SAF 为功能单位，
   核算全链条 GHG 排放；绿电/生物质碳中性假设说明；给出化石路线对比基准。
6. **蒸汽与水平衡**：与 SA-5 协同，量化全厂蒸汽产量/消耗、给水/排水、循环水。

## SA-8 经济评价/TEA（章节：四·8、六·14）

1. **CAPEX**：设备购置（反应器/换热器/除尘器/脱硫脱氯/压缩机/泵/塔器）、安装、管道仪表、电控、
   土建、催化剂首次装填、备品备件、工程设计与总包、contingency（15–25%）。
2. **OPEX**：催化剂年更换费（年运 8000h）、吸附剂/脱氯剂、蒸汽/电/水/化学品、人工、维护、
   三废处置、保险。
3. **产物价值**：路线 A 甲醇/SAF 产量与售价；路线 B 发电量/热电收益。
4. **评价指标**：NPV、IRR、投资回收期、平准化成本（€/MWh 燃料气、元/t 甲醇）、单位投资。
5. **敏感性分析**：原料价、电价、催化剂寿命、焦油出口达标率、产物售价 对 IRR/NPV 的影响
   （HTML 图表展示）。所有投资/成本标"概算/估算，待详细报价确认"。

## SA-9 计算建模/前端（章节：五全部、六·16）

- 独立 Python（3.10+，numpy/scipy/pandas，CoolProp/Cantera 可选）；纯前端单文件 HTML
  （内嵌 Pyodide），含输入区/输出区/图表区/CSV-JSON 导出。
- **物性库**：CoolProp/Cantera 在 Pyodide 下体积大、启动慢，允许预计算查表或拟合关联式替代，
  页面注明替代方式与误差范围。numpy/scipy 在 Pyodide 下可用。
- 模型：物料能量平衡（5.2）、反应器设计计算（5.3）、反应动力学（5.4）、催化剂配方与结构（5.5）。
- HTML 交互：Pyodide 加载；输入干气流量/组成/T/P/湿度/焦油/催化剂下拉/空速/目标出口；
  输出物料/能量表、反应器尺寸/压降、焦油/甲烷/氨转化率、深度脱焦油负荷、敏感性图
  （Plotly/Chart.js）、催化剂年费、毒物耐受提示、CAPEX/OPEX/NPV/IRR 敏感性、碳足迹、
  HAZOP 关键联锁状态指示。导出 CSV/JSON，图表存图。
- 每模型至少 1 个文献/工业数据验证对比；公式、参数、假设明示；提供使用手册。

## SA-10 RAM/运维/开停车（章节：四·9、六·11）

1. **可靠性 R/A/M**：关键设备（反应器/压缩机/除尘/脱硫）MTBF/MTTR 假设、系统可用率目标（≥95%）。
2. **催化剂更换窗口与 turnaround**：在线/离线更换、计划检修周期、与气化炉大修同步。
3. **备件策略**：关键备件清单、安全库存、国产化替代。
4. **开停车规程**：首次装填/还原/钝化、升温曲线、投料顺序、联锁投用、正常/紧急停车、催化剂保护。
5. **操作员培训仿真**：基于 SA-9 HTML 的"what-if"工况训练场景建议。
